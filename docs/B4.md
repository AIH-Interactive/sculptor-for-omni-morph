# B4 YSM authority, live state and recovery

Backend predecessor: `069bf61adceeec813a73283d522607fbc8623274`.
Matching client runtime baseline: `9a1d43a6bf069b605bb176a7a99d0b6f4f65bb95`.
The client checkpoint adds production-Java M7 vector verification and shared
protocol documentation; production client adapter wiring remains B5.

The shared YSM service validates authenticated player ownership, equipment
revision, content/schema identity and exclusive publisher scope/session/generation.
All five partitions are required in full snapshots. Delta absence preserves;
present-empty clears. Finite values, bounded indices/collections, event shapes,
contiguous event watermarks and state bases are validated before commit. Exact
retries acknowledge without rebroadcast. Retired publishers and stale generations
cannot overwrite state. Entity-qualified owners are explicitly rejected with
AUTHORITY_UNAVAILABLE; the backend does not advertise entity authority.

Atomic manifest records persist materialized state, original snapshot time,
watermark, bounded resume tail and retired publishers. Full-snapshot TTL is 300s,
event TTL 30s; deltas do not renew the original snapshot deadline. Tail bounds are
32 frames, 262144 encoded bytes and 64 events. Equip/clear/delete atomically revoke
publisher state. A failed manifest replacement publishes nothing. Offline owners
are never simulated. Restart preserves instance identity and data while replacing
server epoch/scoped credentials. Unknown record versions fail closed.

Both socket adapters subscribe before taking a recovery snapshot. They establish
baseline/watermark before deltas/events, suppress duplicates and request recovery
on gaps/lag. A stale cursor gets CURSOR_EXPIRED then a fresh materialized snapshot.
Missing/expired baselines trigger throttled typed SnapshotRequest to owner sessions.
Shared connection queues enforce 32 messages and 262144 bytes across all producers;
expired queued events force recovery, never delayed playback. Slow consumers close
or receive an explicit recovery error. YSM_RECOVERY is now advertised.

The legacy adapter translates existing production M7 YSMS/YSMP data, never protobuf
bytes, in the reserved Ping. Extended subscribers use x-omnimorph-models: ysm;
valid inbound M7 can also declare support. Fragment bounds are 32KiB per message,
480 bytes per packet, two assemblies per owner, 16 per connection, 60s assembly
expiry and CRC32. Normal opaque Ping and echo remain unchanged. Unsupported old
clients get no YSM data but retain equipment notifications. Outbound socket sends
have a five-second deadline.

Legacy combined state/events are reduced atomically into ordered typed frames.
The persisted original source cursor/fingerprint deduplicates across restart;
canonical sequence can advance twice for one legacy message. Full snapshot event
history only sets watermark, never replays. Legacy imported avatar descriptors
have no runtime schema: the first authorized publisher binds it durably and the
same revision/content cannot later change it. No immutable descriptor is rewritten.

Compatibility limit: existing M7 has no snapshot-request/structured-error control
frame. An unchanged old publisher supplies its existing periodic full snapshots;
the adapter does not fabricate a new wire command. This is the supported bridge
boundary, not a claim of a new legacy request capability.

Validation evidence is recorded at the final milestone checkpoint. The suite uses
synthetic identities/models and real loopback HTTP/WS. Restart coverage stops the
application listener, awaits it, reopens durable storage into fresh AppState and
starts a new listener; it is not an OS-process kill or public deployment. Game and
public deployment observation remain MANUAL/PENDING, with client wiring B5/B8.
