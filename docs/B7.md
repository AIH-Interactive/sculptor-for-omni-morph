# B7 endpoint and Debug transport policy

Backend predecessor: `f802614718a0b4e3b054ac8975e637e6e2af7fe0`.
Client predecessor: `bed32c2866637074212fabce04d5d5d1afc5766f`.
Backend production code and the shared schema are unchanged in this checkpoint.

The client uses one immutable normalized origin for authentication, control RPC,
raw resources and WebSocket paths. Bare hosts mean HTTPS/WSS. Explicit HTTP/WS
requires the live Figura Debug setting, including LAN addresses and bracketed
IPv6. HTTPS/WSS stays secure with Debug enabled. Base paths other than an optional
trailing slash, userinfo, query, fragment, unsupported schemes and invalid ports
are rejected. The legacy `/api//auth` path is preserved by the adapter.

The original string editor now validates this policy. A syntactically valid saved
plaintext address survives loading with Debug disabled; it is shown as invalid
and transport remains blocked. Loading settings does not initiate a partial-config
reconnect. Applying Debug revocation immediately retires the plaintext connection,
its epoch, authentication, resources and callback queue. Live permission is also
checked before retries, connection creation, queued WS writes and received frames.
Late authentication cannot transfer its token to a changed address/protocol.
Local models are retained through revocation and failed reconnection.

HTTP redirects are rejected, and a redirect-enabled HttpClient cannot be used by
the production HTTP transport. The JDK WS builder uses the same nonredirecting
client. TLS certificate trust and hostname checks remain enabled. Debug changes
plaintext permission only; NetworkStuff.debug changes logging only. Diagnostics
contain method/origin, status or stable failure category, never request headers,
query/path credentials, authentication response text or private model bodies.

Automated evidence is recorded after the final foreground build gates:

- cloudEndpointSmokeTest checks the URI matrix under both Debug states, both
  adapters rejecting disabled plaintext before any request, live retirement,
  ordered WS queue revocation, rejected late handshake and late inbound frame.
- Actual HTTP listeners prove cross-origin HTTP/WS redirects do not reach the
  credential target, in-flight HTTP is cancelled, retry is blocked, and IPv6
  authority is preserved on an actual request.
- Actual HTTPS listeners use a temporary test CA/certificate trusted only by the
  test client. HTTPS/WSS redirects never reach plaintext; Debug on/off keeps TLS,
  mismatched hostname and untrusted certificates fail. This does not alter the
  production trust store or disable hostname verification.
- cloudProtocolConfigSmokeTest checks the real address field and captures the
  actual logging backend while sending synthetic token/Authorization/cookie,
  private request/response bodies and query/path markers. Sensitive markers are
  absent and the safe method/origin diagnostic is present.
- ysmMaterialNativeSmokeTest exercises actual Configs.DEBUG_MODE apply for each
  protocol: epoch retirement, authentication cancellation, mailbox discard,
  blocked retry, changed-address rejection and retained resident local runtime.
  This remains CPU/native-object evidence, not rendered GUI evidence.
- The paired Rust suite uses the final Java classpath for all six production
  mixed-adapter cases over explicitly authorized local Debug HTTP/WS.
